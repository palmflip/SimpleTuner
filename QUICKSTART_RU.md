# 🚀 Быстрый старт - Тренировка Flux LoRA на H100 SXM

Этот репозиторий настроен для максимально быстрой и эффективной тренировки LoRA персонажа на мощном железе H100 SXM.

## ⚡ За 5 минут до запуска

### 1. Подготовьте датасет локально

```bash
# Создайте папку dataset и поместите туда:
mkdir dataset

# Ваши файлы должны выглядеть так:
dataset/
├── 1.jpg + 1.txt
├── 2.jpg + 2.txt
├── ...
└── 50.jpg + 50.txt
```

### 2. Скопируйте на H100 сервер

```bash
git clone <your-repo>
cd SimpleTuner
# Скопируйте папку dataset на сервер
```

### 3. Убедитесь, что модель на месте

Проверьте путь: `/workspace/models/unet/flux/fluxmania_V.safetensors`

### 4. Запустите тренировку

**Для экспериментов (быстро, 15 минут):**
```bash
./train_flux_fast.sh
```

**Для продакшна (качественно, 35 минут):**
```bash
./train_flux_h100.sh
```

## 📊 Что вы получите

- **Быстрая тренировка**: LoRA rank 16, 768px, ~15 минут
- **Качественная тренировка**: LoRA rank 32, 1024px, ~35 минут
- **Результат**: файл `pytorch_lora_weights.safetensors` готовый к использованию

## 🚨 Если что-то не работает

1. **Out of Memory** → Уменьшите batch_size в config/config.json
2. **Нет датасета** → Проверьте папку dataset/
3. **Медленно** → Проверьте экспорты CUDA в скрипте
4. **Плохое качество** → Улучшите описания в .txt файлах
